# Token Meter

Claude Code와 Codex의 한도·토큰 사용량을 macOS 메뉴바에서 보여주는 앱이에요.

- **다운로드**: [Releases](https://github.com/serendipity1004/token-meter-app/releases/latest)
- **소개 페이지**: https://serendipity1004.github.io/token-meter-app/

이 저장소는 배포용이에요. 다운로드 파일과 소개 페이지만 들어 있어요.

## 설치

1. `.dmg`를 받아 **Token Meter**를 응용 프로그램 폴더로 옮기세요.
2. 처음 실행할 때는 앱을 **우클릭 → 열기**를 선택하세요. (서명되지 않은 앱이라 macOS가 확인을 요구해요)
3. 메뉴바 아이콘을 클릭하면 상세 화면이 열려요.

Token Meter는 비공식 도구예요. Anthropic이나 OpenAI와 관련이 없어요.
