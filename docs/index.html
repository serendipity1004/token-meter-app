무엇을 보여주나요

메뉴바에 한도

도구별로 가장 많이 쓴 한도를 C 94% · X 25%처럼 항상 띄워요. Claude와 Codex 공식 기준인 사용량(%)으로 표시해요.

한도 상세

Claude는 5시간·주간·모델별(Fable 등) 한도를, Codex는 계정 기준 한도를 보여줘요. 리셋까지 남은 시간도 함께요.

토큰 사용량

오늘 쓴 새 토큰과 캐시 읽기를 나눠서 보여주고, 최근 7일 추이와 모델별 사용량도 확인할 수 있어요.

상태줄 연동

Claude Code 상태줄에 남은 한도를 막대로 표시해요. 켜고 끄는 건 메뉴바 우클릭 한 번이면 돼요.

설치

  1. 위 버튼으로 .dmg를 받아 Token Meter를 응용 프로그램 폴더로 옮겨요.
  2. 처음 실행할 때는 앱을 우클릭해서 "열기"를 선택하세요. 그다음 나오는 창에서 "열기"를 한 번 더 누르면 돼요.
  3. 메뉴바에 게이지 아이콘이 나타나면 끝이에요. 클릭하면 상세 화면이 열려요.
왜 우클릭이 필요한가요? 이 앱은 Apple 개발자 서명을 받지 않아서, macOS가 처음 실행할 때 확인을 요구해요. 그냥 더블클릭하면 "확인되지 않은 개발자" 경고가 뜨고 열리지 않아요. 우클릭 → 열기로 한 번만 허용하면 이후에는 그냥 실행돼요. 터미널이 편하면 xattr -dr com.apple.quarantine "/Applications/Token Meter.app"를 써도 돼요.

어떻게 측정하나요

  • 토큰 수는 두 CLI가 남기는 로컬 로그에서 읽어요. ~/.claude/projects와 ~/.codex/sessions예요.
  • Claude 한도는 Claude Code가 저장한 로그인으로 사용량 API를 조회하거나, 상태줄이 넘겨주는 값을 사용해요.
  • Codex 한도는 설치된 Codex CLI에 계정 한도를 물어봐요. 다른 기기에서 쓴 양도 함께 반영돼요.
  • 조회는 15분마다, 그리고 창을 열거나 새로고침할 때 이뤄져요.

개인정보

  • 대화 내용, 코드, 로그인 토큰은 어디에도 전송하지 않아요.
  • 네트워크 요청은 한도 조회 두 가지뿐이에요. Anthropic과 OpenAI의 사용량 엔드포인트로만 나가요.
  • 수집·분석 도구가 없어요. 모든 집계는 이 컴퓨터 안에서 이뤄져요.
Token Meter는 비공식 도구예요. Anthropic이나 OpenAI와 아무 관계가 없고, 두 회사가 만들거나 보증하지 않았어요. 한도 조회에는 공식 문서에 없는 내부 엔드포인트를 사용해서, 각 서비스가 형식을 바꾸면 값이 표시되지 않을 수 있어요. 그럴 때도 로컬 로그 기반 토큰 사용량은 계속 동작해요.

Windows 지원은 준비 중이에요.
